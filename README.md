O site estará disponível em [kmdanilo.github.io](https://kmdanilo.github.io) após a publicação pelo GitHub Pages.

## Sobre o Projeto

Este projeto reúne informações sobre minha trajetória como estudante de Ciência da Computação na Universidade Estadual de Londrina (UEL), com foco em desenvolvimento de software, inteligência artificial e segurança de aplicações.

A interface utiliza uma identidade visual inspirada em terminal e foi desenvolvida para funcionar em computadores e dispositivos móveis.

## Executando Localmente

**Requisitos:** Node.js e npm instalados.

**1. Clone o repositório:**

```bash
git clone https://github.com/KMDanilo/KMDanilo.github.io.git
cd KMDanilo.github.io
```

**2. Instale as dependências:**

```bash
npm install
```

**3. Inicie o servidor de desenvolvimento:**

```bash
npm run dev
```

Acesse o endereço exibido pelo Vite no terminal, normalmente `http://localhost:5173`.

---

## Comandos Disponíveis

| Comando | Descrição |
|---|---|
| `npm run dev` | Inicia o servidor de desenvolvimento |
| `npm run build` | Gera a versão de produção em `dist` |
| `npm run lint` | Analisa o código com ESLint |
| `npm run preview` | Executa uma prévia local da versão de produção |

## Publicação

O projeto pode ser hospedado gratuitamente pelo GitHub Pages usando GitHub Actions. A automação instala as dependências, gera a versão de produção e publica o conteúdo de `dist` sempre que novas alterações são enviadas para a branch `main`.
